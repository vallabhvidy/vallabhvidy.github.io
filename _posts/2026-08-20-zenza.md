<p>Running untrusted user code at scale is one of the trickiest problems in backend infrastructure. You need strict isolation, predictable resource allocation, low latency, and horizontal scalability when hundreds of jobs arrive concurrently.</p>

<p>I built <strong>Zenza</strong> to solve this: an asynchronous distributed benchmarking and execution platform designed to evaluate code solutions securely under heavy traffic bursts.</p>

<h2>Architecture Overview</h2>
<p>The platform separates request ingestion from actual execution:</p>
<pre><code>[Client Web UI]
       │
       ▼ (HTTP / NDJSON Stream)
[FastAPI Gateway] ──(Enqueue Job)──► [Redis Task Queue]
                                           │
                                     (Worker Pool)
                                           ▼
                                 [Docker / Podman Sandbox]
                                 ├── Cgroups (Memory, CPU limit)
                                 ├── Dropped Linux Capabilities
                                 └── Read-only Root Filesystem</code></pre>

<h2>Sandbox Security &amp; Isolation</h2>
<p>Arbitrary user code cannot simply run on the host. Zenza leverages Docker and Podman to enforce defense-in-depth:</p>
<ul>
  <li><strong>Resource Quotas:</strong> Enforced via Linux cgroups (e.g. <code>--cpus="1.0" --memory="128m" --pids-limit=64</code>) preventing fork-bombs and memory exhaustion.</li>
  <li><strong>Network Isolation:</strong> Disabling network egress (<code>--network none</code>) to prevent data exfiltration or external port probing.</li>
  <li><strong>Syscall &amp; Capability Filtering:</strong> Stripping unnecessary capabilities (dropping <code>CAP_NET_RAW</code>, <code>CAP_SYS_ADMIN</code>) and mounting root partitions as read-only.</li>
</ul>

<h2>Realtime NDJSON Streaming (&lt;50ms)</h2>
<p>Instead of waiting for compilation, execution, and comparison passes to finish before returning an HTTP response, Zenza streams status frames back over NDJSON (Newline Delimited JSON). The frontend receives instantaneous feedback as compilation succeeds, execution begins, and individual test cases pass or fail.</p>
