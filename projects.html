Zenza

FastAPI · Redis · Docker/Podman · Python  ·  read post →

An asynchronous distributed benchmarking platform designed to execute and benchmark untrusted code under extreme concurrent loads.

  • Distributed Architecture: Powered by FastAPI and Redis, handling bursts of 500+ concurrent code execution jobs smoothly across horizontal worker queues.
  • Secure Sandboxing: Engineered an isolated execution engine using Docker / Podman, enforcing strict memory limits, CPU pinning, and syscall constraints to compile and run untrusted code safely.
  • Real-time NDJSON Streaming: Cut perceived client latency to <50ms by streaming execution stdout/stderr and status events via NDJSON as the job runs.

micrograd-cpp

C++ · Systems · Autograd · Machine Learning  ·  read post →

A ground-up C++ reimplementation of Andrej Karpathy's micrograd scalar autograd engine.

  • Dynamic Computation Graph: Dynamically records mathematical operations and builds a directed acyclic graph (DAG) for exact reverse-mode automatic differentiation.
  • Neural Network Abstractions: Layered a modular neural network library on top of the engine—providing Neuron, Layer, MLP, and loss function primitives capable of training simple classifiers.
  • Memory Safety: Leveraged std::shared_ptr and weak references to cleanly maintain cyclic graph node lifetimes without leaks.

CubeTimer

GTK4 · LibAdwaita · C / Python / Dart · SQLite · Flathub  ·  read post →

A native GNOME desktop application for speedcubers with 2,900+ active users on Flathub.

  • WCA Compliance: Features official World Cube Association timing specifications, random-state scramble generation, and 15-second inspection countdowns.
  • Statistics & History: Full statistical tracking (Best, Current, Ao5, Ao12, Ao100, deviation) backed by an optimized SQLite persistence layer.
  • Modern Linux Integration: Seamlessly adheres to GNOME HIG using LibAdwaita styling, native dark mode, and desktop shortcut bindings.
